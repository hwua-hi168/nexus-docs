# 通用操作与 FAQ

本章汇总后台的通用操作方式、审计与排错入口，避免在具体业务页面重复说明。

## 一、通用界面操作

| 操作 | 说明 |
| --- | --- |
| 搜索菜单 | 左侧「搜索菜单...」，输入中文名或关键字，点击结果跳转 |
| 页面刷新 | 标题栏右侧的刷新按钮；只刷新当前页数据 |
| 筛选 | 顶部搜索框 + 状态下拉 + 时间范围；改条件后点「搜索」 |
| 分页 | 底部选择每页条数、输入页码、前后页 |
| 排序 | 表头可点击的列支持排序（以页面实际为准） |
| 详情/编辑 | 行尾按钮；详情通常只读，编辑会打开表单 |
| 批量操作 | 勾选行后使用顶部/底部批量按钮；执行前确认选中数量 |
| 导出 | 右上角「导出」；范围一般等于当前筛选结果 |
| 主题 | 左下角切换暗色/亮色/跟随系统 |

## 二、表单与字段约定

- 带 `*` 的字段通常必填。
- 下拉/多选的值来自系统字典；找不到选项时先到「分类管理」或对应目录页维护。
- JSON 字段（如 `statefulset_spec`、`job_spec`、`metadata`）必须是合法 JSON，保存前可先用格式化工具校验。
- 金额、容量、时长等单位以字段标签为准；改价/改容量前确认单位。
- 开关类字段（可用、上架、启用、公开读、推荐）会立即影响前台，操作前确认。

## 三、审计与日志

| 入口 | 能查什么 |
| --- | --- |
| 系统管理 → 安全管理 → 操作日志 | 后台操作：谁、何时、调了哪个接口、结果 |
| 各业务页的「操作日志」 | 该模块的变更记录 |
| 数据迁移 → 迁移日志 | 迁移任务的逐条结果 |
| 通知管理 → 短信/邮件记录 | 通知发送结果与失败原因 |
| 安全管理 → 安全事件 | 登录异常、风控、封禁事件 |

> 排障时先定位「哪个接口/哪次操作」，再用操作日志 + 业务记录交叉验证。

## 四、权限问题排查顺序

1. **能不能进后台**：账号是否 `uid=1`、`authority_id=888`，或角色是否有任意 `/api/v2/admin/*` 策略。
2. **能不能看到菜单**：角色是否有对应菜单 Key（`authority_menu_keys`）。
3. **能不能操作**：角色是否有对应 Casbin 策略（`casbin_rule`）。
4. **后台教程能不能看**：是否有 `GET /api/v2/admin/help/admin-docs/authz`，详见 [权限与访问入口](./access-control)。

常见误区：

- 只看「菜单」不看「策略」：菜单能点，接口 403。
- 只看「策略」不看「菜单」：接口能调，但找不到入口。
- 改完权限没重新登录：会话里的角色/菜单缓存未刷新。
- 给 888 也手工配教程权限：不必要，888 直通。

## 五、生产操作安全清单

| 操作类型 | 执行前 |
| --- | --- |
| 删除（用户/角色/桶/课程/模板） | 确认无在用引用；备份；记录原因 |
| 封禁/注销/退款 | 核实身份与证据；走审批；保留记录 |
| 改价/改容量/改超卖比 | 影响面评估；与业务确认；记录原值 |
| 数据迁移/全量同步 | 测试环境验证；备份；幂等；回滚方案；维护窗口 |
| 安全设置（MFA/IP/地区） | 确认自己不会把自己锁在外面 |
| 权限变更 | 只勾选新增项；不要全选/清空；记录角色与操作人 |

## 六、截图与脱敏

本教程截图来自生产环境只读浏览。自行截图用于培训/工单时：

- 手机号、邮箱、身份证、真实姓名要打码或模糊。
- AccessKey、密码、Cookie、Token 不要出现在截图里。
- 订单/支付/余额等经营数据按需裁剪。
- 不要把后台地址与账号密码一起发到公开群。

## 七、FAQ

| 问题 | 回答 |
| --- | --- |
| 为什么我看不到某个菜单？ | 角色没有对应菜单 Key，或没有对应接口策略；找管理员分配 |
| 为什么点菜单报 403？ | 有菜单没策略；在「角色管理 → 策略」补对应接口 |
| 为什么改了权限没生效？ | 退出重新登录；浏览器强刷；确认改的是当前角色 |
| 后台教程地址是什么？ | `https://www.hi168.com/help/admin/`，需授权角色 |
| 教程权限和菜单权限是一回事吗？ | 不是；教程权限是独立接口策略，不出现在业务菜单 |
| 888 需要分配教程权限吗？ | 不需要，888 直通 |
| 普通用户能看到教程吗？ | 不能；未登录跳登录，登录后无权限显示 403 |
| 前台帮助文档会受影响吗？ | 不会；`/help/` 仍公开 |
| 操作日志能导出吗？ | 以页面实际能力为准；导出前确认筛选范围与脱敏 |
| 生产能不能直接点「全量同步」？ | 不建议；必须按数据迁移章节的前置条件执行 |
