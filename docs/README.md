# Hi168 云平台 — 帮助文档

## 平台简介

Hi168 是一站式云计算服务平台，集成云端应用部署、对象存储（S3）、云端互联、网络仿真、在线编程、AI 助手、镜像与模板、在线教育、竞赛与社区等功能模块。支持容器与虚拟机两种应用运行模式，为用户提供开箱即用的云端工作环境。

## 适用对象

- **个人用户**：部署云端应用、存储文件、搭建网络实验、在线编程与 AI 对话。
- **教师/教务**：课程制作、班级与学生管理、直播授课。
- **学生**：课程学习、练习、直播、班级学习。
- **团队/企业**：通过组织管理共享资源与成员协作。
- **合作伙伴**：通过共创中心查看推广数据与业绩。

## 快速入门

1. 登录 Hi168 平台，进入 **云桌面中心**。
2. 点击左下角 **Hi168** 打开启动菜单，选择要使用的模块。
3. 首次使用「应用中心」时，选择应用 → 部署 → 等待环境就绪。
4. 用「存储管理」保存文件，用「Notebook」在线编程。
5. 学习场景进入「课程学习」，教师进入「课程制作 / 教务管理」。
6. 保存应用状态可用「快照」或「应用模板」。

> **遇到问题**：优先查阅对应模块文档；仍无法解决时，通过启动菜单「工单中心」提交工单。
